# angela-interface-skills（中文别名「毫厘」）

一套帮 agent 把产品界面做好的技能合集：界面评审、UI 打磨、动效、排版、色彩、无障碍、布局与界面文案，特点是给精确数值而不是空泛原则。别名取这套技能的看家本事——较真毫厘：描边 1.5px 不是 2px、按压缩放 0.96 不是 0.95，界面好坏就差在这些毫厘上。

本仓是 dukangalex 名下的自有化项目：自有命名、自有文档、与上游脱钩独立维护。来源与致谢见 CREDITS.md，许可证为 MIT（原文见 LICENSE）。

## 安装

```bash
npx skills add dukangalex/angela-interface-skills
```

也可作为 Claude Code 插件使用（插件名 angela-interface-skills，清单在 .claude-plugin/）。

## 技能一览

领域类（知识与评审标准）：

- **better-interface**：跨无障碍、布局、文案、排版、色彩、UI 打磨、动效七个维度评审一个界面，出一份按优先级排序的报告。
- **better-ui**：打磨表面与图标，给圆角、光学对齐、阴影、图标状态的精确数值。
- **better-motion**：决定什么该动、怎么动，给时长、缓动、缩放、距离的精确数值与进入/退出/图标切换/共享布局/拖拽的配方。
- **better-typography**：定字阶、间距、字体特性、换行、截断与标点，评审文本渲染。
- **better-colors**：生成色板、命名语义令牌、格式转换、测对比度，搭建与检查色彩系统。
- **better-accessibility**：按 WCAG 2.2 评审并修复键盘与焦点、ARIA、可达名称、表单、屏幕阅读器播报、动效与缩放。
- **better-layout**：定分组、对齐、阅读顺序、响应式结构，并为译文留足空间，布局在缩放、翻译、镜像时不崩。
- **better-writing**：写与评审界面文案（标签、错误提示、空状态、确认文案），贴合产品语气并告诉用户下一步。

流程类（动手干活，用户点名触发）：

- **interface-review**：评审一个分支、PR 或未提交改动引入的界面问题与回归。
- **explain-interface**：从一个线上 URL 或截图，讲解一个网站、视觉效果或动画是怎么做的。
- **break**：把选定组件在所有可达场景下渲染到临时页做压力测试。
- **build-design**：照 Figma 文件或设计图还原 UI，沿用项目既有令牌与组件。
- **state-machine**：把选定组件的全部状态渲染到临时页（带模拟数据与切换器），逐个状态打磨。
- **variant**：给选定组件做多个变体，迭代挑选。
- **afk**：人不在时通读项目、找改进点、在本地分支上落地最好的几个并留报告。
- **upskill**：研究项目与历史会话，提出最省时间的技能/钩子/自动化建议，经挑选后落地。

技能正文保持英文原文：各技能 frontmatter 的 description 与本节条目对应，且评审口径的精确性依赖原文措辞。仓库维护规约见 AGENTS.md。

## 维护

按自有化项目定时维护制月度巡查上游与同类项目：候选长处先入台账，收编须自有化落地并过基线复测。本仓使用口径：本地试用只启用其中 14 个，afk 与 upskill 因与本方调度纪律不合，仅存仓不用。
